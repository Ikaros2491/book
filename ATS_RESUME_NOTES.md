# ATS Resume Versions — How to Use

These files are built for **Applicant Tracking Systems** (online job portals). Keep the designed sidebar PDFs for emailing recruiters/humans; upload the **ATS** files when a website parses your resume.

## Files

| Role | Best for uploads | Also available |
|------|------------------|----------------|
| Executive / private FA | `Corey_Wagner_Resume_ATS_Flight_Attendant.docx` | `.pdf`, `.html` |
| Flight Coordinator (Solairus-style) | `Corey_Wagner_Resume_ATS_Flight_Coordinator.docx` | `.pdf`, `.html` |

Prefer **`.docx`** when the portal allows Word. Use the ATS **PDF** if the form requires PDF (text is selectable / machine-readable).

## What was optimized (research-backed)

- Single-column layout (no sidebar, tables, text boxes, or graphics)
- Contact info in the document body (not header/footer fields)
- Standard headings: Professional Summary, Skills, Certifications, Professional Experience, Education, References
- Standard font (Calibri) and normal bullets
- Keywords mirrored from each job description where truthful (Part 91, cabin readiness, catering/provisioning, confidentiality, flight itinerary, trip requests, crew travel arrangements, FAR, Microsoft Office/Windows, etc.)
- Acronyms spelled out on first use where helpful (e.g., Federal Aviation Regulations (FAR))

## Designed vs ATS

- **Sidebar one-pagers** (`Corey_Wagner_Resume_Executive_FA.pdf`, `Corey_Wagner_Resume_Flight_Coordinator.pdf`): human-facing
- **ATS versions** (`*_ATS_*`): portal / parser-facing

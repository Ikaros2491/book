# USA drivable RVs under $1,500

## Deliverable

Open **`USA_Drivable_RVs_Under_1500.xlsx`**:

1. **RV Candidates** — curated motorhomes/camper vans with embedded photos, prices, leak/running signals, and clickable listing links  
2. **FB Marketplace Searches** — ready-made Facebook Marketplace search URLs for 42 U.S. metros (open while logged into Facebook)  
3. **Search Notes** — methodology and tier definitions  

Also included: `USA_Drivable_RVs_Under_1500.csv`, `USA_Drivable_RVs_Under_1500.html`, and `listing_photos/`.

## Important limitation

Facebook Marketplace requires login from this environment (every city redirected to `/login/`). Nationwide results below were collected from **Craigslist** (~300 regions). Use sheet 2 to run the same queries on Marketplace in your browser.

## Criteria

- Motorized RVs only (Class A/B/C, motorhome, camper van) — not towable trailers  
- Price ≤ $1,500  
- Prefer running/drives + no-leak claims (see tier column)

## Reality check

At this budget, almost every listing is a 1970s–90s project. **Zero pristine turn-key runners** were found. Verify title, roof, and drivability in person.
